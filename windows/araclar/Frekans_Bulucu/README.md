# Frekans Bulucu

**Durum:** Tarayıcıda doğrudan açılabilen, çevrimdışı referans tonu aracı.

`index.html` dosyasını güncel bir tarayıcıda aç. Bir nota seçildiğinde frekans Hz olarak gösterilir ve sinüs tonu üretilebilir.

- A0–C8 aralığında nota/frekans eşleştirmesi.
- Ağ bağlantısı gerektirmeyen arayüz.
- B3 frekans eşleştirmesi düzeltilmiştir; varsayılan ton genliği düşüktür.
- Bu araç bir ölçüm cihazı değildir ve SPL kalibrasyonu yapmaz.

**Güvenlik:** Başlangıçta bilgisayarın ve arayüzün sesini düşük tut. Test tonunu kulaklıkla yüksek seviyede uzun süre dinleme.
